## Featured: RepoLens

[RepoLens](https://github.com/asadabbas717/RepoLens) is a shipped, deterministic repository engineering-quality auditor with Python-first static analysis. It produces evidence-backed findings, transparent scores, and console, JSON, and standalone HTML reports without executing target code.

- Published on [PyPI](https://pypi.org/project/repolens-engineering/) as `repolens-engineering`, under Apache-2.0.
- Typed domain models and separate acquisition, orchestration, analysis, scoring, reporting, and configuration boundaries.
- Windows/Linux CI on Python 3.13/3.14 and PyPI Trusted Publishing through GitHub Actions OIDC.
- [Architecture](https://github.com/asadabbas717/RepoLens/blob/main/docs/architecture.md), [scoring](https://github.com/asadabbas717/RepoLens/blob/main/docs/scoring.md), and [scope/limitations](https://github.com/asadabbas717/RepoLens#safety-and-limitations) are documented. Static scores do not certify correctness or security.

```bash
python -m pip install repolens-engineering
repolens scan .
```
